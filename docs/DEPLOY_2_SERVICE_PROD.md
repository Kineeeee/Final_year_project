# 2-Service Production Deployment (Web + API)

This setup deploys:
- web: Nginx serving built Vite assets and reverse-proxying API + Socket.IO
- api: Node.js backend

Database and Redis are expected to be managed services (recommended for production).

## 1) First-time server setup

1. Install Docker Engine and Docker Compose plugin.
2. Create deployment folder:
   - /opt/phaser-snake
3. Copy repository contents to /opt/phaser-snake.
4. Copy env template and fill real values:
   - cp deploy/.env.prod.example deploy/.env.prod

## 2) Required env values (deploy/.env.prod)

- GHCR_OWNER: GitHub org/user that owns container packages
- IMAGE_TAG: usually latest (or commit sha)
- CORS_ORIGINS: your game domain, ex: https://game.example.com
- MONGO_URI: managed MongoDB connection string
- REDIS_URL: managed Redis URL
- JWT_SECRET and REFRESH_SECRET: strong secrets
- COOKIE_SECURE (optional): true for HTTPS, set false only if you temporarily serve plain HTTP by IP

## 3) Local production test before pushing

From repository root:
- docker build -f apps/server/Dockerfile.prod -t local/phaser-snake-api:dev apps/server
- docker build -f apps/web/Dockerfile -t local/phaser-snake-web:dev apps/web

Then set in deploy/.env.prod:
- GHCR_OWNER=local
- IMAGE_TAG=dev

And run:
- docker compose -f deploy/docker-compose.prod.yml up -d

## 4) CI/CD flow

Workflow file:
- .github/workflows/cicd-2service.yml

Stages:
1. Test matrix:
   - apps/server: npm ci, lint, test
   - apps/web: npm ci, lint, test/build
2. Build and push images to GHCR:
   - ghcr.io/<owner>/phaser-snake-api
   - ghcr.io/<owner>/phaser-snake-web
3. Deploy via SSH:
   - pull latest images
   - recreate services with docker compose up -d

## 5) GitHub secrets to configure

- DEPLOY_HOST: server public IP/domain
- DEPLOY_USER: SSH user
- DEPLOY_SSH_KEY: private key content
- GHCR_PAT: GitHub PAT with package read permission

GitHub repository variable:
- GAME_PUBLIC_URL: public URL of your game, ex: https://game.example.com

## 6) Domain and TLS

Recommended:
- Put Cloudflare or reverse proxy with TLS in front of port 80
- Set CORS_ORIGINS to exact HTTPS game domain
- Keep API internal (no host port publish)

## 7) Rollback

1. Pick previous IMAGE_TAG (sha tag generated by workflow).
2. Update deploy/.env.prod IMAGE_TAG.
3. Run:
   - docker compose -f deploy/docker-compose.prod.yml pull
   - docker compose -f deploy/docker-compose.prod.yml up -d
